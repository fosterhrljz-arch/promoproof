# PromoProof v2.2 — release notes

This is a focused refinement of v2.1. The financial, rule engine, saved-data and CSV model modules are unchanged.

- Quantified guidance explains profit shortfalls, additional sales, inventory capacity, discount ceilings, campaign-cost alternatives and negative-margin loss limits.
- Scenario comparison prioritizes offers that pass goal checks and labels every sales case as meeting or missing the goal.
- The guide uses expandable actual screenshots and a plain-English worked example.
- Mobile typography, touch controls, progressive guidance and workspace navigation are refined.
- Direct PDF export and a dedicated print report preview include all scenarios and frozen reviews.
- A cross-tab storage recovery issue is fixed: a readable recovered library clears its earlier blocked state.
- Homepage language now makes the scenario nature of results explicit.
- The release includes an illustrated English README, complete source, tests and synthetic sample exports.

See QA-v2.2.md for completed checks and the explicit native Windows launch/print verification limit. AgentGit publication is manual; automatic uploads were not enabled.
